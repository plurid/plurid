# Looks

GENERATED by `scripts/generate-tables.mjs` from `LOOK_TOKENS` / `LOOK_BASES` in `@plurid/plurid-themes` — do not edit; run `pnpm docs.tables`. The look is the one vocabulary every piece of engine chrome is drawn from: 44 tokens, emitted as `--plurid-<token>` custom properties on the application's element (`[data-plurid-application="<id>"]`), derived by `deriveLook` from a base of a few colours. Set it with `look` (a preset name, a base, or `{ preset, tokens }`); override any token from CSS with a more specific selector. The vocabulary and its rules: [DESIGN.md](./DESIGN.md); the knob and the slots: [CONTROL_SURFACE.md](./CONTROL_SURFACE.md#the-look).
