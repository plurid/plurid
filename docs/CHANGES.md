# `space.changed`: every kind

GENERATED by `scripts/generate-tables.mjs` from `PLURID_CHANGE_KINDS` in `@plurid/plurid-data` — do not edit; run `pnpm docs.tables`. A host subscribes once to `space.changed` and reads `{ kind, value }`; `PluridChangeKind` is the type of `kind`, and a test holds it equal to this list.

| kind | value |
| --- | --- |
| `selection` | the selected plane ids, `string[]` |
| `tree` | the whole tree of planes, roots with their children (`TreePlane[]`) |
| `links` | the plane links (`PlaneLink[]`) |
| `activePlane` | the active plane id, `''` for none |
| `isolate` | the isolated plane id, `''` for none |
| `layoutResolved` | whether the roots have been laid out, `boolean` |
| `loading` | whether the space is still booting, `boolean`: `false` once its first layout is resolved |
| `history` | the arrangement history: `{ canUndo, canRedo, undoDepth, redoDepth, past, future }` |
| `motion` | the camera's motion state: `idle`, `tween`, `gesture`, `fling` |
| `bookmarks` | the runtime bookmarks: `Record<name, encoded viewpoint>` (the configured presets and home are not in it) |
| `docked` | the page presentation: the docked page id, `''` when the camera left the page |
| `culling` | the culling pass: `{ hidden, frozen, detached }` counts |
| `plane` | the answer to a `token`: `{ token, planeID, route, parameters, parentPlaneID }`, once the plane exists (at once when it was already open) |
| `refused` | the answer to a `token` no plane will answer: `{ token, route, reason }` (`unregistered`: no plane is registered at the route; `noParent`: the parent plane is not in the space) |
| `describe` | the answer to `space.describe`: `{ token, inspection }`, the inspection as `api.inspect()` gives it |
| `command` | what a `space.command` did: `{ id, ran, reason }` (`unknown`, `disabled`, `needsKey`, `declined`) |
| `focus` | whether the keyboard focus is inside the space, `boolean` |
| `planeError` | a plane threw while rendering and its boundary caught it: `{ planeID, route, message }` (the plane shows its error card; the rest of the space goes on) |
